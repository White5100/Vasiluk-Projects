
1. Какие инструменты графического редактора наиболее полезны для извлечения информации о размерах, цветах и шрифтах?  
   Полезны панель свойств/Inspector, инструменты измерения расстояний, выбор цвета и просмотр параметров текста. В Figma также удобно смотреть размеры объекта, положение по X/Y, заливку, обводку, шрифт, размер и межстрочный интервал.
2. Как правильно организовать структуру CSS-переменных на основе данных из макета?  
   Значения из макета удобно вынести в `:root`: отдельно цвета, типографику, размеры контейнера, радиусы, тени и интервалы. В проекте эти значения собраны в `styles/variables.css`, а основные правила — в `styles/main.css`.
3. Какие метрики из макета наиболее критичны для точной верстки?  
   В первую очередь важны ширина контейнера, размеры секций и элементов, отступы, размеры шрифтов, межстрочные интервалы, цвета, радиусы и положение элементов относительно сетки.
4. Как определить систему сетки, используемую в макете и перенести ее в CSS Grid или Flexbox?  
   Нужно определить количество колонок, ширину контейнера, промежутки между колонками и правила выравнивания. Для карточек CodeFlow используется CSS Grid с тремя колонками на десктопе; для шапки и ряда действий — Flexbox.
5. Какие сложности возникают при переносе типографики из графического макета в веб-страницу?  
   На отображение текста влияют доступность выбранного шрифта, его начертание, метрики, размер экрана, переносы строк и настройки `line-height`. Поэтому кроме размера шрифта важно проверить ширину текстового блока и межстрочный интервал.
6. Как обрабатывать адаптивность, когда в макете представлен только десктопный вариант?  
   Нужно определить логические точки перехода, при которых элементы перестают помещаться. Затем перестроить сетку, уменьшить типографику и отступы, скрыть или изменить навигацию при необходимости. В этой работе предусмотрены брейкпоинты 900 и 560 px.
7. Какие инструменты браузера помогают сравнивать сверстанную страницу с оригинальным макетом?  
   DevTools: Elements для структуры, Computed для итоговых CSS-значений, вкладка Styles для проверки правил, Responsive/Device Toolbar для разных размеров экрана и измерение размеров элементов через инспектор.
8. Как правильно экспортировать изображения из графического редактора для веб-использования?  
   Выбирать формат по назначению: SVG для векторной графики и простых иконок, WebP/JPEG для фотографий, PNG для изображений с прозрачностью. Перед экспортом следует проверить размер и оптимизировать файл.
9. Что делать, если в макете используются шрифты, которых нет в веб-доступе?  
   Проверить наличие веб-лицензии и возможность подключения шрифта. Если подключение невозможно, подобрать близкий веб-шрифт и проверить размеры, переносы и межстрочные интервалы, чтобы сохранить визуальную иерархию.
10. Какие методологии помогают поддерживать соответствие между макетом и кодом при дальнейших изменениях?  
    Помогают единая система переменных, понятная структура компонентов, соглашения по именованию классов, дизайн-токены, повторное использование компонентов и регулярная визуальная проверка страницы по макету.
