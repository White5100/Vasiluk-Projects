1. Назначение Viewport: Тег <meta name="viewport"> сообщает браузеру мобильного устройства, как управлять масштабированием и размерами страницы. Без него мобильные устройства будут отображать десктопную версию сайта в сильном уменьшении, делая текст нечитаемым.
2. Использованные подходы: В работе применен Responsive-подход (отзывчивый дизайн), при котором макет плавно перестраивается и адаптируется под любые размеры экранов за счет использования гибких сеток (Flexbox/Grid), относительных величин и медиа-запросов.
3. Mobile First подход: Это стратегия проектирования, при которой сайт сначала верстается для маленьких экранов смартфонов, а затем, с помощью медиа-запросов min-width, расширяется для планшетов и десктопов. Преимущество — оптимизация производительности и фокус на главном контенте.
4. Единицы измерения в адаптивности: Предпочтительны относительные единицы: % — для ширины контейнеров, rem/em — для масштабируемых шрифтов и отступов, vw/vh — для привязки элементов к физическим размерам окна просмотра (экрана).
5. Функция clamp(): Принимает три параметра: минимальное значение, предпочтительное (динамическое) и максимальное. Она позволяет шрифтам плавно расти или сжиматься в зависимости от ширины экрана, не выходя за установленные безопасные рамки.
6. Брейкпоинты и их определение: Использованы точки 1024px (переход на планшеты), 768px (смартфоны/схлопывание меню) и 480px (компактные телефоны). Эти значения определены на основе стандартных разрешений популярных устройств на рынке.
7. Медиа-запросы @media: CSS-правило, позволяющее применять блоки стилей только при выполнении определенных условий (например, размера экрана). Синтаксис: @media (max-width: 768px) { .element { property: value; } }.
8. Max-width против Min-width: max-width применяет стили для экранов МЕНЬШЕ указанной ширины (подход Desktop First). min-width применяет стили для экранов БОЛЬШЕ указанной величины (подход Mobile First).
9. Адаптивные изображения: Чтобы картинка не ломала разметку, ей задают max-width: 100%; (запрещает быть шире родителя) и height: auto; (сохраняет пропорции при сжатии). Также используется объектное свойство object-fit.
10. Инструменты разработчика для адаптивности: Встроенная в браузеры панель DevTools в режиме эмуляции устройств (Responsive Design Mode). Она позволяет менять размеры экрана, проверять контрольные точки и тестировать touch-события.
