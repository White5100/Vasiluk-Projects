 1. В чем разница между innerHTML и textContent и когда следует использовать каждый метод?

`innerHTML` позволяет читать и изменять HTML-разметку внутри элемента. Его используют, когда действительно нужно вставить HTML. `textContent` работает только с текстом и не интерпретирует содержимое как HTML. Для вывода обычного пользовательского текста безопаснее использовать `textContent`.

 2. Как работает делегирование событий (event delegation) и какие преимущества оно дает при работе с динамическими элементами?

Делегирование событий основано на всплытии события. Обработчик устанавливается на общего родителя, а внутри него проверяется `event.target`. Это позволяет обрабатывать события элементов, которые были добавлены в DOM позже, и уменьшает количество отдельных обработчиков. В работе такой подход используется для удаления элементов динамического списка.

 3. Какие методы используются для поиска элементов в DOM и в чем разница между getElementById, querySelector и querySelectorAll?

`getElementById` ищет один элемент по его уникальному `id`. `querySelector` возвращает первый элемент, соответствующий CSS-селектору. `querySelectorAll` возвращает коллекцию всех элементов, соответствующих селектору.

 4. Как предотвратить стандартное поведение элемента при обработке событий и когда это необходимо?

Для этого используется `event.preventDefault()`. Например, при обработке отправки формы можно предотвратить переход или перезагрузку страницы и выполнить собственную проверку данных JavaScript.

 5. В чем разница между classList.add() и className для работы с CSS классами?

`classList.add()` добавляет отдельный класс, не удаляя остальные классы элемента. `className` задаёт всё значение атрибута `class`, поэтому при его использовании можно случайно заменить существующие классы. Для точечного управления классами удобнее `classList`.

 6. Как создать новый элемент и добавить его в DOM несколькими способами? Какой способ наиболее эффективен?

Элемент можно создать через `document.createElement()`, заполнить его свойствами и добавить через `appendChild()` или `append()`. Также HTML можно вставлять через `innerHTML`. Для безопасного создания отдельных элементов и работы с пользовательскими данными удобнее `createElement` вместе с `textContent`.

 7. Что такое всплытие событий (event bubbling) и как работает метод stopPropagation()?

Всплытие означает, что событие после возникновения на дочернем элементе распространяется к его родителям. `stopPropagation()` прекращает дальнейшее распространение события по DOM. Это может использоваться, когда родительский обработчик не должен реагировать на событие дочернего элемента.

 8. Как получить данные из формы и в чем разница между методами сбора form data?

Можно обращаться к элементам формы напрямую через `form.elements`, использовать `FormData(form)` или получать значения отдельных полей. `FormData` удобно использовать для получения набора полей формы в виде пар имя-значение, а `form.elements` даёт прямой доступ к элементам формы.

 9. Какие события используются для обработки ввода данных и в чем разница между input, change и keyup?

`input` срабатывает при изменении значения во время ввода. `change` обычно срабатывает после завершения изменения значения элемента. `keyup` возникает при отпускании клавиши. Для отображения введённого текста в реальном времени подходит `input`, поэтому он использован в работе.

 10. Как оптимизировать производительность при частых манипуляциях с DOM?

Нужно уменьшать количество отдельных изменений DOM, объединять операции, использовать делегирование событий для большого количества динамических элементов и по возможности сначала формировать изменения вне документа. При большом количестве элементов полезно использовать `DocumentFragment` и избегать лишних чтений и записей layout.
